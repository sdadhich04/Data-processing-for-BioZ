# Bio-Impedance Data Analysis Toolkit

This repository contains scripts for processing, analyzing, and visualizing bio-impedance measurements collected from liquids, phantoms, and experimental media.

The goal of this repo is to serve as a growing toolkit for validating impedance systems, comparing conductive media, and generating publication-ready plots.

---

## 📦 Current Features

### Data Visualization Scripts

#### `Liquid_Validation_Plot.m`

Generates comparison plots of impedance magnitude and phase across solution types.

Useful for:

* Quick visual inspection of experiment results
* Comparing conductivity across liquids
* Detecting measurement drift or trends

---

#### `Liquid_Validation_BoxPlot.m`

Creates boxplots to visualize the distribution of impedance and phase measurements for each solution.

Useful for:

* Evaluating measurement variability
* Detecting outliers
* Comparing repeatability between media

---

The goal is to build a reusable MATLAB toolkit for impedance experiments rather than one-off scripts.
